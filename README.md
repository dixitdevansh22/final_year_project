## ✨ What is Nexora?

**Nexora** is a modern, full-featured analytics dashboard built for businesses that want real-time visibility into their performance. Designed with a clean, data-first UI — it transforms raw numbers into clear, actionable insights.

> *"Don't just collect data. Understand it."*

## ⚡ Getting Started

### Prerequisites

```bash
node >= 16.0.0
npm  >= 8.0.0
```

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/dixitdevansh22/final_year_project.git

# 2. Navigate into the project
cd final_year_project

# 3. Install dependencies
npm install

# 4. Start the development server
npm start
```
